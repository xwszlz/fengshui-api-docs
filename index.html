01 / 平台定位

一个学科创建宣言，
而不是一份商业计划书

胡焱照人文风水观的坐标是清晰的：它不是传统形法，也不是纯粹科学，而是一种 可被政策、市场与公众共同使用的空间文化中介工具。平台的全部设计，都围绕这一坐标展开。

POSITION 01

从形法到文化哲学

「文化自信源于道」，风水是生态文明的一种东方表达。关注精神、伦理、社群、生态四重秩序，而非止于建房取向与吉凶砂水。

POSITION 02

从经验到可复现路线

建立「GIS + 风水文化层」技术路线：易学定格局、遥感与水文量化生气、问卷与大数据回注人轴，形成可重复、可验证的分析管线。

POSITION 03

从民间术数到公共工具

雄安起步区生态廊道论证、绩溪龙川与查济古村保护、刑侦「时—空—象」模型——让风水真正进入公共决策、文旅 IP 与教学体系。

已被验证的实践
雄安新区「九龙入首」转译为九条微丘—湿地廊道景观结构，被中规院采纳
绩溪龙川 / 查济风水故事线组织游线，水口、朝山、祠堂成为可解说节点，年游客量提升 30%
刑侦应急「时—空—象」模型辅助定位，为易学实证化提供罕见公开案例
必须正视的争议
科学化程度「生气」「卦运」仍依赖专家赋权，可重复性不足
文化本质主义易滑向地缘文化优越论，需在多元文明对话中自我节制
商业边界高端定制服务与「惠民」初衷存在张力
平台的基本态度： 把争议写进白皮书，把边界写进提示词，把负面结果写进出版计划。学术自觉不是包装，是护城河的一部分。
02 / 理论内核

「易—地—人」三轴模型

三轴不是比喻，而是一条技术路线：易轴给时间与方位的先验，地轴给空间的可测量变量，人轴给社群记忆与心理安全感的量化入口。 三者在同一坐标系内耦合，才可能产出可证伪的假设。

易

易轴 · 定大格局

以《易》学时空观确定元运、卦气与方位先验。输出的是假设的初值域，而不是结论。

地

地轴 · 量化「生气」

DEM、遥感时序、水文网络、生物多样性等可测量变量，把「生气」拆成可回归、可检验的空间指标。

人

人轴 · 回注模型

姓氏谱系、聚落记忆、产业需求、心理安全感——问卷量表与行为大数据双轨采集，回注三轴耦合模型。

05 / 证据标准

监管级决策，只认监管级证据

把「我觉得有效」换成可审计的数字门槛。四级证据体系对应四类用途，越界即视为违规交付。

LEVEL 1A核保定价 / 储备金假设

多队列元分析 + MR 三角验证 + 自然实验，外部验证 ≥3

C-index > 0.80
校准 p > 0.05 · NRI > 5%
LEVEL 1B风险分层 / 产品设计 / 再保谈判

大规模队列 + TMLE / DML + 敏感性分析，外部验证 ≥2

C-index > 0.78
校准良好 · 临床效用正向
LEVEL 2健康管理 / 咨询建议 / 研发假设

中等队列或纵向分析 + 倾向得分 / 单一 IV，外部验证 ≥1

方向一致 · 机制合理 · 可干预
LEVEL 3 / 4仅假设生成 / 内部探索

探索性、小样本、机制推演、专家共识——必须标注证据不足
